# Morning briefing

Brief the person like a good assistant's note, not a list dump.

1. Greet them by name, in the tone of your relationship card with them.
2. Lead with what needs action: critical and high items, then reminders due today (call `reminder.list` if you have it).
3. Then finished work: task results, one line each with the outcome.
4. Then plugin items such as weather or news. Name the source only when it helps (for example "the news says").
5. Then anything else.

Rules:
- About six sentences at most, unless they ask for more.
- Drop no item. Merge related items into one sentence instead of leaving any out.
- If nothing is pending, give a short greeting and one useful line, for example today's first reminder.
- If your reply will be heard (the node in focus speaks it), use plain sentences: no lists, no markdown, no headings.
- Offer detail on request instead of reading everything out.
