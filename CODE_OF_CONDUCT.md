# Code of Conduct

## Our expectations

Keith is built in the open by people with different backgrounds and views. Keep it that way:

- Be respectful. Disagree with ideas, not with people.
- Keep discussion on the work: the code, the specs, the docs and the decisions.
- No harassment, insults, threats, personal attacks or unwanted sexual content, in issues, pull requests, comments or any other project space.
- Do not publish someone else's private information without their consent.
- Do not post secrets, credentials or exploit details in a public place. Report them as described in [SECURITY.md](SECURITY.md).

## Reporting a problem

Report a conduct problem privately through GitHub: use the Security tab of `viandwi24/keith` and choose "Report a vulnerability", or email the maintainer listed on the GitHub profile of `viandwi24`. Include what happened, where, and any links or screenshots. Do not reply to the behaviour in public to settle it.

## Enforcement

Maintainers review every report and may:

- ask for an apology or a change in behaviour,
- remove, edit or hide comments, issues, pull requests or commits that break these expectations,
- limit or block a person's access to the repository.

Maintainers decide what counts as a breach and how to respond. If you think a decision was wrong, write to the maintainer again through the same channel with new information.

## Scope

These expectations apply to every project space: the repository, its issues and pull requests, and any chat or event run by the maintainers for Keith.
